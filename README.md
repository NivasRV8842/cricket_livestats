# cricket_livestats
The Cricket Livestats Dashboard is an interactive data analytics application developed using Python, Streamlit, and MySQL. The system retrieves recent cricket match data through the Cricbuzz API (via RapidAPI), stores the information in a relational database, and presents insights through an easy-to-use web dashboard.

The primary goal of this project is to demonstrate how live sports data can be integrated with a database and transformed into meaningful analytics. The application allows users to fetch match data from the API, manage player information using CRUD operations, and explore visual insights such as match distribution by teams, venues, and match status.

This project combines API integration, database management, and data visualization to simulate a real-world sports analytics platform that could be useful for analysts, sports enthusiasts, or fantasy cricket platforms.
